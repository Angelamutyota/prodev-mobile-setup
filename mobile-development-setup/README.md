# Mobile Development Setup (Expo + React Native)

## Objective
This project documents the setup and testing of a mobile development environment using the Expo Framework for React Native. The goal is to ensure the development environment is ready for upcoming mobile projects.

---

## Development Environment

- **Operating System:** Windows / macOS / Linux (specify yours)
- **Node.js Version:** v18.x.x (LTS)
- **npm Version:** v9.x.x
- **Code Editor:** Visual Studio Code
- **Mobile Device:** Android / iOS (specify model if you want)
- **Expo Go:** Installed from official app store

---

## Expo Go Installation

1. Visited https://expo.dev/go
2. Installed Expo Go from:
   - Google Play Store (Android) / Apple App Store (iOS)
3. Opened the Expo Go app
4. Logged into an Expo account successfully
